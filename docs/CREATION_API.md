# 创作 API

管理员在原生 ComfyUI 导出 API JSON，经 Studio 工作流审核、真实冒烟和发布后，到「创作 → API 设置」为酒馆创建一个专用 Key。为 Key 勾选具体发布版本。发布新版本后，可显式为同一 Key 增加或撤销版本授权。撤销版本授权也会停止该 Key 查询该版本的历史和产物。

## 部署与连接

创作 API 在「创作 → API 设置」提供三档并存的鉴权模式（切换弱鉴权后，既有专用 Key 仍可按各自权限独立使用）：

1. **强鉴权（默认，专用 API Key）**：客户端携带 `Authorization: Bearer <专用 Key>` 访问独立域名或同端口子路径 `<SITE_URL>/comfy/creation`。
2. **弱鉴权（URL 路径短码，免中继直连推荐）**：直接将短码嵌入接入地址（同端口子路径 `<SITE_URL>/comfy/c/<短码>` 或独立域名 `<CREATION_COMFY_URL>/t/<短码>`）。SillyTavern、柏宝绘等不支持自定义请求头的客户端只需填写该 URL 即可浏览器直连或服务端转发，无需部署 Nginx 中继；支持随时一键重置路径短码。
3. **免鉴权（本机 / 受信内网直连）**：直接使用 `<SITE_URL>/comfy/creation` 或独立监听端口（如 `http://127.0.0.1:8189`）免密直连，默认仅放行本机回环源 IP（可按需勾选允许局域网/容器私网，并支持配置前端 Origin 白名单）。

默认可通过 Studio 同端口子路径直接接入，无需配置独立域名；遇到不允许填子路径的客户端插件时，可在「创作 → API 设置」填写 `1024–65535` 独立监听端口。弱鉴权通道默认自动开放所有当前激活（`active`）的发布版本，也可切换为仅开放手动勾选的版本。

## 提交与预热

单任务运行时限和空闲保留时间可填写正整数分钟。预算和 Colab 实例的实际可用时长仍会影响任务和保留窗口。

酒馆可以用同一连接切换完整 API JSON。检查匹配时，可选择目标 Key，结果显示具体发布版本、提取的参数和不匹配的位置。模型文件和连线参与匹配。若版本只在开放字段的默认值上不同，可收窄该 Key 的授权版本。通过 Studio 提交图片参数的客户端可以在绑定位置传入 `studio-asset:<UUID>`，素材须属于该管理员的「创作 API」项目。酒馆本地文件名暂无法转译。

`POST /prompt` 入队后返回 `prompt_id`。带同一 `Idempotency-Key` 重试会返回同一个任务。客户端轮询 `GET /history/{prompt_id}`，然后使用其中的文件参数调用 `GET /view`。历史产物按实际 ComfyUI 输出节点返回。取消请求使用带 `prompt_id` 查询参数的 `POST /interrupt`，酒馆 1.19.0 的断开回调无法传递该参数。

关闭自动启动时，先在 API 设置手动启动所选工作流。智能模式可在预热后保留一段发图窗口。手动启动运行发布快照的内部预热图，按配置的单任务时限执行，也受 Colab 实例实际寿命约束。预热图不会进入作品库。就绪记录显示已运行的实例、进程与 GPU，Worker 提交正式请求时再次检查进程并复用同一模型缓存。显存驻留受 ComfyUI 缓存策略与设备容量影响。切换依赖环境时，运行时可换用新进程并复用已校验的磁盘文件。

## bero 真机验收

2026-11-20，使用 SillyTavern 1.19.0 服务端实际调用其 ComfyUI 探测、生成、轮询和取图接口。公网创作 API 通过独立的 HTTPS 域名提供服务。酒馆使用私网中继注入同一把 Key。两份工作流均在 NVIDIA L4（23,034 MiB）执行。原生会话关闭，创作链路独立工作，且在停用原生内部反代时完成了生成验证。

| 工作流 | Studio 任务 | 实测结果 |
| --- | --- | --- |
| Anima in Rael 1.0.0 | 冷启动 `5f575185-87a1-439b-b6a4-a02c95acaff6`，预热 `eca77150-b348-4039-8cfd-ae840b594532`，出图 `2fa4f017-a445-4210-9c13-175befe87d89` | Studio 入队到完成从 366.0 秒降至 118.0 秒。酒馆预热后 120.3 秒取回 PNG。冷启动超过试验客户端 300 秒的响应头时限，Studio 后续完成产物登记。 |
| Moss Image SFT 1.0.0 | 预热 `7798f9a3-aafc-49ab-96a4-b9137bfd3aec`，出图 `19d29240-89a8-4f4a-b914-d122feb64180` | 工作流默认 T4，API 设置 L4，复用同一台 L4。酒馆预热后 41.4 秒取回 PNG。 |

两次正式出图分别与自己的预热使用同一实例、租约和进程。切换到 Moss 时，同一实例切换到了新的 ComfyUI 进程。预热合并重复点击，未登记作品。关闭自动启动且无可复用实例时返回启动提示。固定模型输入被修改、Key 无版本授权、其他 Key 查询历史均被拒绝。保留模式的一分钟空闲到期后，已确认真实租约释放，就绪状态失效。

一分钟单任务上限测试 `bfb453c1-ebc1-4bb3-b2b8-6067cad0212f` 在真实 L4 恢复依赖后超时，实例仍有剩余硬时限。系统记录了失败、清理了真实租约，并保留验收前保存的运行配置。通过真机验收后，移除了普通任务和批次对智能、保留模式的临时验证开关。

## 离线验证

后端测试使用本地数据库和模拟传输，覆盖 A100 默认工作流使用 API 的 L4 设置入队、版本歧义、幂等重试、产物归属与撤销、已预热实例复用、批次交接和独立任务截止。前端验证包括 TypeScript 与生产构建、contract 和 Node 测试。另用 bero 真实页面验证了 390 px 与 1440 px 下的管理员入口、刷新后读取配置、未保存提示和工作流匹配。
